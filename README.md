# apps

A small collection of downloadable apps, distributed as self-contained `.sbr` packages.

Each `.sbr` is a single, ready-to-run binary — download one and install it with your app client.

## Catalog

| App | What it is |
|-----|-----------|
| `calc` | A calculator with an expandable panel for extra functions |
| `canvas` | Signed first-party layered drawing and image editing |
| `real` | A thermostat dial you can nudge up and down |
| `ignite` | A control panel with keys that light up while held |
| `logbook` | Signed first-party notes with persistent search, import, and export |
| `tazama` | Browse and search videos, and open one to watch |

## Install

Point your client at this repository and pull an app by name, e.g.:

```
get calc
```

That downloads `calc.sbr` and installs it locally.
