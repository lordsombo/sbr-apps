# Labs

Labs contains unsigned SDK interaction examples. These packages are deliberately outside the
Stable root catalog and are not installable through Forge's trusted Stable transaction.

They demonstrate small UI ideas only; none owns a first-party Sibuor product identity:

| Example | Purpose |
|---|---|
| `calc` | Expandable calculator-panel interaction |
| `ignite` | Key press/hold feedback |
| `real` | Adjustable dial interaction |

Inspect or verify a local package with `mw inspect` / `mw verify`. A future explicitly enabled
Labs channel must label unsigned content and keep it separate from Stable trust decisions.
